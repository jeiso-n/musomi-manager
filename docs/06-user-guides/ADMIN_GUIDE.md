# Musomi Manager — Administrator Quick Guide

## 1. Sign in

1. Start the Musomi Manager desktop application.
2. Enter the administrator username and password supplied by the system owner.
3. If sign-in fails, confirm the backend is online and ask the system owner to verify your account. Do not share your password.

## 2. Set up the school

Before teachers enter marks, confirm that the school has:
- A current academic year and its terms
- Class levels, classes, and streams
- Subjects and subject topics
- Teacher accounts and class/subject assignments
- Student records with correct admission numbers, classes, and streams

Use the corresponding sections in the Admin navigation. Check names and assignments carefully before the term begins.

## 3. Manage students and student logins

1. Open **Students**.
2. Create or update the student's personal and class information.
3. Check the admission number, class, stream, and active status.
4. Use **Create Student Logins** only for students who do not yet have linked portal accounts. Initial credentials are displayed once; distribute them privately.
5. For an existing linked student, use **Reset Password** to set that student's individual permanent password. Confirm the student identity before saving.
6. Never reuse one password across all students. Do not send passwords in a group chat.

Deactivating a student also disables their student portal access. Reactivating an eligible student restores access.

## 4. Manage teachers and assignments

1. Create or verify the teacher account.
2. Open teacher assignments.
3. Assign the correct class, stream (where applicable), subject, and academic year.
4. Ask the teacher to sign in and confirm that **My Classes** shows only the intended assignments.

## 5. Reports

1. Confirm the correct term and class/stream filters.
2. Generate reports only after marks and comments have been reviewed.
3. Check the generated report count and inspect sample PDFs.
4. Remember that class performance summaries are based on generated report snapshots. Regenerate reports after correcting marks if the summary must reflect those changes.

## 6. Protect school data

- Use an individual account; do not share administrator credentials.
- Use strong, unique passwords.
- Keep the database server private.
- Confirm backups are running and periodically verify a restore.
- Report incorrect marks or unexpected access immediately.
- Do not delete database records manually.

## 7. Before publishing results

Confirm the term, class, stream, student roster, assessment maximums, and missing marks. Published marks become visible to students. Correct errors through the approved workflow and audit trail.
