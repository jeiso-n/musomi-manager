# Musomi Manager — Teacher Quick Guide

## 1. Sign in

Open the Musomi Manager desktop application and sign in with your teacher account. Contact the administrator if your assigned classes or subjects are missing.

## 2. Check your classes

Open **My Classes**. Confirm that each class, stream, and subject shown is one you are assigned to teach. If an assignment is incorrect, ask the administrator to correct it.

## 3. Create an assessment

1. Open **Assessments** and choose the create action.
2. Select the correct class, stream (if used), subject, and term.
3. Enter the assessment title, type, date, and maximum score.
4. Select at least one topic that the assessment covers.
5. Save the assessment as a draft.
6. Confirm that the assessment appears under the intended class and subject.

Do not create duplicate assessments to work around a selection or validation error.

## 4. Enter marks

1. Open **Mark Entry** and select the correct assessment.
2. Check the roster before entering marks.
3. Enter each student's mark within the assessment maximum.
4. Use the save/commit action and confirm the saved indicator or success message.
5. Review the entered count and return to any missing students.
6. A score of zero is a valid recorded score. Leave a mark blank only when it is genuinely not recorded.

If a save fails, do not assume the mark was stored. Refresh the grid and verify the value before continuing.

## 5. Review and publish

1. Open the assessment review view.
2. Check the class, stream, subject, term, maximum score, and topic tags.
3. Confirm every expected student has a recorded mark.
4. Resolve missing marks before publishing.
5. Publish only after checking the marks carefully. Published results become visible in the student portal.

## 6. Comments and reports

Use the available comment/report functions for the correct student and term. Review names and results before generating or sharing a report. Ask the administrator if a report snapshot is outdated after marks have changed.

## 7. Good practice

- Never enter marks while unsure which class or assessment is selected.
- Never share your login credentials.
- Report incorrect rosters, duplicate students, or missing assignments to the administrator.
- Keep a school-approved source record until the school confirms its data-entry and backup procedures.
