# 15. Prioritized recommendations

Order is by production impact and dependency, with each item tied to inspected evidence.

| Priority | Task | Evidence | Completion target |
|---:|---|---|---|
| 1 | Replace hardcoded actor, school, and user IDs with authenticated principal and tenant context; enforce ownership in services. | `backend/src/main/java/com/musomi/manager/controller/api/TeacherMarkApiController.java`: `private static final Long TEACHER_ID = 1L;`; `AdminStudentImportApiController.java`: `SCHOOL_ID = 1L`. | Requests operate only as the authenticated actor within their authorized school; cross-tenant/role tests pass. |
| 2 | Implement and test PDF report generation, storage, and downloads. | `backend/src/main/java/com/musomi/manager/controller/api/ReportApiController.java`: `"Report generation is not available yet"` and HTTP 501. | Generate downloadable, correct term reports from published marks; errors and access checks covered by tests. |
| 3 | Replace student-portal fixture data with service-backed, identity-scoped data. | `backend/src/main/java/com/musomi/manager/controller/web/StudentDashboardWebController.java`: `model.addAttribute("firstName", "Sarah")`; `StudentMarksWebController.java` hardcodes sample marks. | Dashboard, marks, results, and reports display only the logged-in student's persisted records. |
| 4 | Integrate audit recording transactionally for key mutating operations. | `backend/src/main/java/com/musomi/manager/controller/api/AdminUserApiController.java`: `// TODO(backend): audit_log when V023 lands`; no production caller for `AuditService.log(...)` found. | Create/update/deactivate/publish/import/report changes produce attributable audit records. |
| 5 | Make backend context/integration tests reproducible with PostgreSQL and require a green CI-equivalent run. | `backend/target/surefire-reports/com.musomi.manager.MusomiManagerApplicationTests.txt`: `Connection to localhost:5432 refused`; CI already provisions `postgres:16` in `.github/workflows/ci.yml`. | Local documented test command and CI both pass including migrations and Spring context load. |
| 6 | Implement or explicitly remove/mark the unsupported student CRUD, change-password, logo, teacher roster, and student identity API routes. | `docs/shared/API_CONTRACT.md` §5 documents `POST /auth/change-password`; `backend/src/main/java/com/musomi/manager/controller/api/AuthApiController.java` maps login, me, logout only. | Contract and running route map agree, with role/status/body tests for every supported endpoint. |

| 8 | Require configuration secrets in all live-capable profiles; remove credential logging and rotate any shared development credentials. | `backend/src/main/resources/application.properties`: `jwt.secret=${JWT_SECRET:musomi-manager-dev-secret-change-in-production-min-32-chars-long}`; `DevDataSeeder.java` logs `admin / password123`. | No default signing key or logged credential can be used in a deployment configuration. |

| 10 | Refresh `docs/STATUS.md`, schema constraints, API route status, and build/test instructions from current code. | `docs/STATUS.md`: `Entities | **2**` and `API controllers | **1**`; current inventory has 24 entities and 20 API controllers. | Status and contracts match source, migration DDL, and current passing test/build evidence. |

**Recommended release gate:** do not call the v1 ready until priorities 1–5 are implemented and verified, the documented core user paths are complete, and at least one real school has completed a recorded acceptance run, as required by `docs/master/MASTER.md` §4.
